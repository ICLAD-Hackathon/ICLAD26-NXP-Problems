01

SoC Top-Level Interconnect

2x3 mesh graph
The CPU AXI4-Lite master enters the mesh at node (0,0) via a TileLink NI. AES0 sits at node (1,0) and AES1 at node (1,1). Each of the 6 nodes has one router, one NI, and one SRAM. Horizontal links connect East(p2)↔West(p3); vertical links connect North(p0)↔South(p1). Boundary ports have no neighbour. Use this diagram to wire up the mesh interconnect.

03

TileLink-UL Router

XY routing
Each router node exposes the ports drawn below: North(p0), South(p1), East(p2), West(p3), and a Local(p4) port to its NI. Routing is XY-first: packets hop East/West to reach the target column, then North/South to reach the target row, then deliver to Local. Address bits [31:28] = dest_x, [27:24] = dest_y. Determine the port count and bus widths from the interface shown.
Link wiring principle: Each mesh link is a single shared TileLink bus. The East port (p2) of one router and the West port (p3) of its eastern neighbour are the same physical wires — they must be connected together, not driven independently. The same applies to the North (p0) and South (p1) ports of vertically adjacent routers.
04

TileLink NI — AXI4-Lite to TL-UL Bridge

bridge
One Network Interface per node. The NI bridges the AXI4-Lite master (CPU or internal) to the TileLink-UL A/D channels. The NI acts as an AXI slave on one side and a TL-UL master on the other. The AXI and TL-UL data and address widths match; determine them from the bus signals shown.
05

AXI-Lite SRAM

memory slave
Each node contains one AXI4-Lite SRAM used as the node's local memory. Determine its depth, data width, and address width from the interface signals drawn; the address bus is sized to address every word of the memory.
06

AES-128 Engine

aes0 @ (1,0)    aes1 @ (1,1)
Two AES-128 engines are instantiated as aes0 (at node 1,0) and aes1 (at node 1,1). Both use ip_type: aes128 but different names. Each engine takes a 128-bit key and 128-bit plaintext and outputs 128-bit ciphertext. The done output is a single-cycle pulse after 10 rounds. The busy output is high during computation.
07

IRQ Aggregator

8-source
The IRQ aggregator collects up to 8 interrupt sources and outputs cpu_irq and cpu_irq_id[2:0]. Only 2 sources are wired: src[0] = aes0_done, src[1] = aes1_done. Sources [7:2] are tied to 0.
08

Node Address Encoding

memory map
The TileLink router uses the top 8 bits of the 32-bit address for XY routing: bits [31:28] = dest_x, bits [27:24] = dest_y. The remaining lower bits form the local offset into the destination SRAM.
